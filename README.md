# Kotoventure – Korea Touring Game Adventure

> 한국을 알고 싶거나 한국 여행을 계획하는 전 세계 사람들을 위한 **스마트폰 여행 서바이벌 게임**.
> 공항/항구에 내리는 순간부터 귀국까지, 진행형 여행 코스를 따라가며 **교통·숙박·음식·돈·생활예절·법규·날씨·의료**를 터치로 결정하며 배웁니다.

|---|---|

| 퍼블리싱 명칭 | **Kotoventure** |
| 플랫폼 | iOS · Android (Expo / React Native, 하나의 코드) |

| 회원가입 | 닉네임 + 출발 국가만 (익명 계정, 비밀번호 없음) |

## 1. 폴더 구성

```
Kotoventure/
├─ app/        스마트폰 게임 앱 (Expo SDK 58, React Native, TypeScript, react-native-svg)
├─ admin/      관리자 웹 (Vite + React + TypeScript)
├─ shared/     앱·관리자 공용: 데이터 타입, 게임 엔진(점수·추천·검증), 기본 미션 콘텐츠
└─ supabase/   DB 스키마(SQL)·보안 정책(RLS)·시드 데이터·테스트 계정·결제 웹훅
```

```
 [스마트폰 앱] ──읽기(공개 콘텐츠)/쓰기(내 진행·프로필)──▶ [Supabase: Postgres + Auth]
                                                              ▲
 [관리자 웹] ──관리자 계정(role=admin)으로 모든 CRUD────────────┘
 [RevenueCat] ──구매 웹훅──▶ [Edge Function] ──▶ entitlements 테이블
```

- 앱은 **번들된 기본 콘텐츠**를 갖고 있어 오프라인에서도 바로 실행되며, 서버가 연결되면 `content_stamp()`로 변경 여부를 확인해 새 콘텐츠를 자동으로 내려받습니다. → 관리자 웹에서 고친 내용이 **앱 업데이트 없이** 반영됩니다.

## 3. 테스트용 무료 DB 연결 (추천: Supabase)

**추천 이유**: 무료 플랜(Postgres DB + 인증 + 익명 로그인 + Edge Functions)으로 개발·테스트 전 과정을 비용 없이 진행할 수 있고, 운영으로 그대로 확장됩니다.

### A. 로컬 (가장 안전한 테스트 – Docker 필요)
```bash
npm i -g supabase
```
```bash
supabase start
```
- `supabase/config.toml` 이 마이그레이션 → 기본 콘텐츠 → **테스트 계정**까지 자동으로 넣습니다.
- 출력되는 `API URL`과 `anon key`를 아래 env 파일에 넣으세요.

### B. 클라우드 무료 프로젝트 (테스트 전용 프로젝트 권장)
1. https://supabase.com → New project (Free)
2. **SQL Editor**에서 순서대로 실행
   1. `supabase/migrations/20261118000000_init.sql`
   2. `supabase/seed.sql` (기본 미션 콘텐츠)
   3. `supabase/seed_test_accounts.sql` (**테스트 프로젝트에서만!**)
3. **Authentication → Sign In / Providers → Anonymous sign-ins 켜기** (앱 간편 가입에 필요)
4. Project Settings → API 에서 URL / anon key 복사

### env 설정
```
app/.env      EXPO_PUBLIC_SUPABASE_URL=...   EXPO_PUBLIC_SUPABASE_ANON_KEY=...
admin/.env    VITE_SUPABASE_URL=...          VITE_SUPABASE_ANON_KEY=...
```
(각 폴더의 `.env.example` 참고. `.env`는 git에 올라가지 않습니다.)

### 테스트 계정
| 용도 | 계정 | 비밀번호 |
|---|---|---|
| 관리자 웹 | `admin@example.com` | `Admin1234!` |
| 일반 플레이어 (기본 앱 보유) | `player@example.com` | `Player1234!` |

- 실제 운영 관리자 지정: 해당 사용자로 가입 후 SQL `update profiles set role='admin' where id='<user uuid>';`
- 결제 테스트: **iOS Sandbox 테스터**(App Store Connect → Users and Access → Sandbox), **Google Play 라이선스 테스터**(Play Console → 설정 → 라이선스 테스트). 실제 청구되지 않습니다. 개발 빌드/데모 모드에서는 앱 안의 **[TEST STORE] 모의 결제창**이 뜹니다.

### 4-3. 플레이 방식
- 장면(Scene)마다 2D 배경 + 내 일행 캐릭터 + 대화 상대가 등장하고, **스텝**이 순서대로 진행됩니다.
  - 📜 내레이션 · 💬 대화(한국어 표현 학습) · ❓ **터치 결정**(그림 보기 포함) · 📖 지식카드 · ⚡ 이벤트(날씨/건강/돈/법규)
- 선택에 따라 **체력 ⚡ / 지갑 ₩ / 매너 🙇** 이 변하고, 체력이 0이 되면 강제 휴식(비용 발생).
- 스텝마다 **여행 타입 필터**가 있어 같은 코스라도 개인/커플/친구/단체에 따라 다른 상황이 나옵니다(예: 혼밥 1인분, 커플 한복·자물쇠, 단체 펜션 인원 추가).
- 코스 완료 시 **결과 화면**: 등급(S/A/B/C), 점수, 정답률, 주제별 배운 카드, 배운 한국어 표현, 실제 여행 체크리스트.
- **가이드북**: 모은 카드를 주제별로 다시 보기. **내 정보**: 언어(영/한), 여행 타입·캐릭터 변경, 긴급전화(112/119/1330/1345), 참고 환율 계산기.

### 4-4. 실전 시뮬레이션 (🎮 0~100점)
실제 기계·창구를 그대로 재현해, 직접 조작하며 미션을 수행합니다. 실수할 때마다 감점되고, 점수는 정답률·최종 점수에 반영되며 환전 손실·수수료·요금은 지갑에서 차감됩니다.

| 시뮬레이션 | 진행 내용 | 사용 코스 |
|---|---|---|
| 💱 **환전** | 내 나라 통화(출발 국가 기준)가 강조된 **환율 전광판** 읽기(기준율 vs 살 때) → **얼마를 바꿀지 결정**(공항/시내 수수료 차이, 미션 권장액) → 받은 돈 세기 → 지폐 고르기 → **지폐 4종·동전 4종 앞/뒷면 실제 비율**로 확인(인물·도안·크기·위조방지 요소) | 서울(공항), 제주 |
| 🏧 **ATM** | Global ATM 기기(화면·키패드·카드 투입구·**통장 투입구**·명세표·현금 출구): 언어 → 해외카드 출금 → 카드 넣기 → PIN(키패드 가리기) → 계좌 종류 → 금액 → **DCC(자국통화 결제) 거절** → 수수료 → **카드 먼저 회수** → 현금 → 명세표, 보너스: **통장정리** | 부산(항구) |
| 🟧 **T머니** | 카드 앞/뒷면 → 편의점에서 **현금으로 구입** → 역 **충전기**(메뉴 → 카드 올리기 → 금액 → 지폐 투입, 카드 결제 불가 → 충전 중 떼지 않기) → **개찰구**(진입금지/승차/우대용 구분) → 하차 태그 → 버스 승·하차 태그 | 서울, K-컬처(김포) |
| 💵 **현금 결제** | 가게·노점에서 품목과 합계를 보고, **내 지갑의 실제 지폐·동전**(실물 비율 그림)을 눌러 계산대에 올림 → 결제(부족하면 버튼 비활성) → **거스름돈 계산** 확인 → 거스름돈이 지갑에 들어옴. 딱 맞게 내면 보너스, 더 작은 돈으로 낼 수 있었는데 큰 돈을 내면 감점, 현금 부족 시 ATM/카드 대체 | 서울 명동 노점, 부산 호떡, 경주 황남빵, 제주 해녀, 한강 편의점 |
| 🚄 **KTX** | **노선도**에서 하차역 찾기(경주=신경주) → 노선 고르기 → **승차권 자동발매기**(한/영 전환, 도착역, 인원, 시간표·매진·도착기한, 호차·좌석·순/역방향, 카드 결제) → **승차권 읽기**(호차·좌석) → **출발 안내판**에서 타는 곳 찾기 | 경주(인천 → 서울역) |
